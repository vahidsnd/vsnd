# نئون براول (Neon Brawl) — سند طراحی بازی

> پلتفرم فایتر دوبعدی آنلاین (سبک Super Smash Bros / A Few Quick Matches) با آرت‌استایل اختصاصی «نئون استیکر»، برای مایکت و گوگل‌پلی.

---

## ۱. هسته بازی (Core Loop)

```
ورود → جایزه روزانه → انتخاب مبارز → بازی (۲–۴ دقیقه) → جایزه (سکه/XP/مأموریت/رتبه)
   ↑                                                                    ↓
   └──── خرید مبارز/اسکین، پاس فصل، جعبه ← فروشگاه ← تبلیغ ×۲ سکه ←────┘
```

* **هدف مبارزه:** به جای نوار جان، هر ضربه **درصد آسیب** حریف را بالا می‌برد. هرچه درصد بیشتر، دورتر پرت می‌شود. هر کس از **مرز صحنه (Blast Zone)** بیرون بیفتد یک **جان (Stock)** از دست می‌دهد.
* **مسابقه:** ۱v۱ (۳ جان، ۵ دقیقه)، ۲v۲ و همه‌با‌هم (۲ جان، ۴ دقیقه). در پایان وقت: بیشترین جان، سپس کمترین درصد.
* **شروع:** شمارش ۳-۲-۱-برو (۳ ثانیه). بازگشت پس از سقوط روی سکوی ظهور با ۲.۵ ثانیه آسیب‌ناپذیری.

## ۲. مکانیک‌ها (همه در `shared/src/sim.ts`)

| دسته | مکانیک |
|---|---|
| حرکت | راه رفتن، دویدن (دو بار زدن جهت)، پرش کامل/کوتاه (نگه‌داشتن یا رها کردن پرش)، پرش هوایی (۱ تا ۴ بسته به مبارز)، سقوط سریع، رد شدن از سکوی نازک (پایین زدن)، کنترل در هوا |
| حمله زمینی | Jab (ترکیبی)، Tilt جلو/بالا/پایین، حمله در حال دویدن، **اسمش** جلو/بالا/پایین با **شارژ** (نگه‌داشتن) |
| حمله هوایی | Nair, Fair, Bair, Uair, Dair (اسپایک رو به پایین) + تأخیر فرود (Landing Lag) |
| حرکات ویژه | ۴ ویژه اختصاصی برای هر مبارز: پرتابه، یورش، برگشت به صحنه (بالا+B)، پایین+B |
| دفاع | سپر (کاهش با استفاده، شکستن سپر = گیجی)، غلت، جاخالی درجا، جاخالی هوایی جهت‌دار |
| گرفتن | گرفتن (سپر را می‌شکند) + ۴ پرتاب (جلو/عقب/بالا/پایین)، رهایی با زدن دکمه‌ها |
| لبه صحنه | آویزان شدن خودکار با آسیب‌ناپذیری (فقط بار اول)، بالا رفتن، پرش از لبه، حمله از لبه، غلت از لبه، رها شدن |
| فیزیک ضربه | فرمول ناک‌بک اسمش (درصد، آسیب، وزن، BKB/KBG)، Hitlag (مکث ضربه)، Hitstun، **DI** (کنترل جهت پرتاب)، کمانه از زمین، **Tech** (سپر هنگام برخورد) |
| ویژه‌ها | زره (Super Armor)، ضدحمله (Counter)، تله‌پورت، کوبش زمین با موج ضربه، بمب و مین انفجاری، باد (Windbox) |

### کنترل‌ها
* **موبایل:** جوی‌استیک شناور + دکمه‌های A (ضربه)، B (ویژه)، پرش، سپر، گرفتن، 💥 (اسمش). جهت سریع + A هم اسمش است. لرزش (Haptic) هنگام ضربه سنگین.
* **کیبورد:** WASD/جهت‌ها، Space پرش، J ضربه، K ویژه، L سپر، U گرفتن، I اسمش.
* **گیم‌پد:** A ضربه، B ویژه، X/Y پرش، RB/تریگر سپر، LB گرفتن، استیک راست = اسمش جهت‌دار. تا ۴ گیم‌پد برای بازی محلی.

| **بولدر** غول سنگی | سنگین | کند، قوی، زره | پرتاب سنگ / شانه زره‌دار / پرش موشکی / زمین‌لرزه | رایگان |
| **زفیر** پرنده باد | هوایی | ۴ پرش هوایی، سبک | تندباد (هل دادن) / پر تیز / اوج‌گیری / گردباد | ۲۵۰۰ سکه / ۲۵۰ الماس |
| **ولت** ربات صاعقه | دوربُرد | پرتابه قوی | گوی برقی / جهش صاعقه / تله‌پورت / میدان مغناطیسی | ۳۰۰۰ / ۳۰۰ |
| **کیرا** شمشیر ماه | شمشیرزن | بُرد بلند | شوریکن / ضربه پرشی / برش صعودی / ضدحمله | ۳۵۰۰ / ۳۵۰ |

## ۴. طراحی مرحله (Level Design) — `shared/src/stages.ts`

| صحنه | چیدمان | هدف طراحی | باز شدن |
|---|---|---|---|
| پشت‌بام نئونی | ۳ سکو (کلاسیک «بتلفیلد») | استاندارد رقابتی، کمبوهای سکویی | از ابتدا |
| دوجوی ماه | صاف، بدون سکو | ۱v۱ خالص، بدون فرار | از ابتدا |
| بازار شناور | ۲ سکوی بالا-پایین رونده | زمان‌بندی، فشار متغیر | از ابتدا |
| راکتور | ۱ سکوی چپ-راست رونده، صحنه کوچک | بازی تهاجمی، ناک‌اوت زودتر | سطح ۳ |
| ویرانه‌های آسمان | ۳ سکو، صحنه پهن | بازی ۴ نفره، فضای فرار | سطح ۶ |

* لبه‌ها با نقطه نئونی مشخص‌اند (لبه = جای آویزان شدن).
* مرز صحنه‌ها طوری تنظیم شده که اسمش جلو یک مبارز متوسط را از وسط صحنه حدود ۱۲۰–۱۴۰٪ ناک‌اوت کند (تست خودکار دارد).

## ۵. آرت‌استایل «نئون استیکر»

* شخصیت‌های گرد و توپُر با **خط دور ضخیم جوهری** (حس برچسب) + رنگ تخت + یک هایلایت + **رنگ درخشان (Glow)** اختصاصی هر اسکین.
* دست و پای شناور (بدون بازو/ساق) → خوانایی کامل روی صفحه کوچک موبایل.
* **دست/پای ضربه دقیقاً روی Hitbox واقعی حرکت قرار می‌گیرد** و هاله نئونی می‌گیرد؛ یعنی «هر چه می‌بینی همان ضربه است».
* پس‌زمینه‌های پارالاکس رویه‌ای (شهر، ماه و پاگودا، گنبد و فانوس، راکتور، ابرها)، سکوهای نئونی.
* افکت‌ها: جرقه ضربه به اندازه ناک‌بک، حلقه موج، ستاره ضربه سنگین، **پرتو نوری ناک‌اوت** + لرزش و فلش صفحه، رد پرتاب، گرد و غبار، دود انفجار.
* همه گرافیک کدنویسی شده (بدون فایل تصویر) → حجم APK بسیار کم و اسکین‌های جدید فقط با یک پالت رنگ.
* صدا و موسیقی سینث‌ویو کاملاً سنتز شده با WebAudio.

## ۶. سیستم اقتصادی (`shared/src/economy.ts`)

دو ارز:
* **سکه** (ارز نرم): از بازی، مأموریت، ورود روزانه، جعبه، پاس، سطح.
* **الماس** (ارز سخت): خرید درون‌برنامه‌ای + مقدار کم از پاس، ورود روزانه، هر ۵ سطح.

### منابع (Sources)
| منبع | مقدار |
|---|---|
| مسابقه آنلاین | برد ۴۵ / باخت ۱۸ سکه + ۶ به‌ازای هر ناک‌اوت + جایگاه؛ رقابتی ×۱.۲۵؛ مقابل CPU ×۰.۶ |
| اولین برد روز | +۱۰۰ سکه، +۵ الماس، +۵۰ XP |
| مأموریت روزانه (۳ عدد) | ۱۲۰–۳۰۰ سکه، بعضی الماس |
| ورود روزانه ۷ روزه | ۱۰۰ سکه ... روز هفتم ۵۰۰ سکه + ۴۰ الماس |
| بالا رفتن سطح | ۱۵۰+ سکه، هر ۵ سطح ۲۵ الماس |
| جعبه رایگان (با تبلیغ) | هر ۴ ساعت |

### مصرف‌ها (Sinks)
مبارزها (۲۵۰۰–۴۰۰۰ سکه)، اسکین‌ها، جعبه نئون (۹۰ الماس)، تبدیل الماس به سکه (۵۰ → ۱۰۰۰ ... ۴۸۰ → ۱۲۰۰۰).

### ضد سوءاستفاده
* همه جوایز آنلاین **فقط روی سرور** محاسبه می‌شوند (شبیه‌سازی معتبر سرور).
* مسابقه کمتر از ۲۵ ثانیه فقط ۲۰٪ جایزه.
* جایزه مسابقه CPU سقف روزانه ۴۰ بازی دارد.
* تبلیغ جایزه‌دار حداکثر ۲۰ بار در روز.
* توکن خرید فقط یک بار قابل استفاده است.

### پاس فصل (۳۰ روزه، ۳۰ مرحله، ۳۵۰ XP هر مرحله)
* مسیر رایگان: سکه، هر ۵ مرحله الماس، هر ۱۰ مرحله جعبه.
* مسیر پریمیوم: ۶ اسکین انحصاری، ۴۰ الماس هر ۴ مرحله، جعبه، سکه بیشتر.

### رتبه‌بندی (`shared/src/rank.ts`)
برنز ← نقره ← طلا ← پلاتین ← الماس ← استاد ← افسانه (هر کدام ۳ دسته). Elo با ضریب متغیر، پاداش برد پیاپی، باخت نرم‌تر در برنز. ریست نرم هر فصل (نصف فاصله تا ۱۰۰۰). جدول ۱۰۰ نفر برتر.

### جعبه‌ها
احتمال‌ها **در بازی نمایش داده می‌شوند** (الزام گوگل‌پلی): سکه ۵۵٪، الماس ۲۰٪، اسکین ۲۰٪، مبارز ۵٪. تکراری → سکه.

## ۹. آنلاین (`server/`)

* **سرور معتبر (Authoritative)** با ۶۰ تیک در ثانیه؛ همان شبیه‌سازی `shared` روی سرور اجرا می‌شود (تقلب در نتیجه ممکن نیست).
* کلاینت: **پیش‌بینی سمت کاربر + تطبیق (Reconciliation)** — ورودی شما بدون تأخیر اجرا می‌شود و با هر Snapshot سرور (۳۰ بار در ثانیه) بازشبیه‌سازی و نرم اصلاح می‌شود.
* ارسال تکراری ورودی‌ها در برابر گم شدن بسته؛ فشرده‌سازی وضعیت.
* صف‌یابی بر اساس MMR با پنجره بازشونده؛ پر کردن با ربات (برچسب «ربات» نمایش داده می‌شود) بعد از ۱۵ ثانیه (عادی) / ۳۰ ثانیه (رقابتی).
* اتاق خصوصی با کد ۵ حرفی، تیم‌ها، ربات، انتخاب صحنه و جان.
* قطع اتصال: ۸ ثانیه بعد ربات جایگزین می‌شود؛ وصل شدن دوباره به همان مسابقه.
* شکلک‌ها (Emote) در مبارزه.

## ۱۰. نقشه راه پیشنهادی (بعد از انتشار)
1. آیتم‌های داخل صحنه (اختیاری در اتاق خصوصی).
2. مبارز جدید هر فصل (فقط داده + پالت).
3. تورنمنت هفتگی و کلن.
4. ریپلی (شبیه‌سازی قطعی است؛ ذخیره ورودی‌ها کافی است).
5. Rollback کامل برای پینگ‌های بالا.
